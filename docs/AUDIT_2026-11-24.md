Scope: the `claude-harness-hub` repo (docs, `.spec/`, `.claude/`, `.harness/`, plugin, workflows), checked against the code on `main` at aea17d8. Other repos were out of scope.

Part 1 lists what this audit fixed. Part 2 lists findings left for Charlie because they change behaviour, a required check, or what spokes receive. Part 3 is the redundancy and consolidation review.

## 2. Flagged for Charlie's decision (not changed)

1. **The hub has no slice gate on its own PRs.** `harness-gate.yml` is reusable (`workflow_call`) and only spoke callers use it. Either add a hub caller or drop the hub from the "must pass" rule for good.
2. **`/learn` edits a locked file in spokes.** Step 1 appends to `.claude/harness-rules.md`, which ENGINE LOCK refuses in a spoke. Step 0 already uses `.claude/project-rules.md`. Recommend that step 1 does the same, and promotes to the hub only on request.
3. **Main-thread warning text says "refused".** `main-thread-guard.mjs` writes "Main thread edit refused" and "Main thread Bash refused" although the call goes ahead. This text lands in the event log and `triage-events` output. Small wording change; tests match only the tail of the message.
4. **The circuit-breaker message points to commands threads cannot run** (`/prep-audit diff`, `/implement sonnet`), and `engineer-sonnet` does not load in threads.
5. **`.claude/settings.json` allow-list has stale v2.2 entries**, including `git push --force-with-lease origin claude/vibe-command-center-v2.2`. The force push is hard-blocked anyway, but the allow entry reads like a permission.
6. **`bin/restart-dashboard.sh` is allow-listed in `main-thread-guard.mjs` but does not exist.**
7. **Setup script still exits 0 when the plugin download fails** (open since 5 Nov).
8. **Dashboard tab badges are hard-coded.** Security shows "B+" always; the agent and command counts fall back to 4 and 10 (the real counts are 12 and 17).
9. **Slice 11.11 (remove Referee trailer checks)** was approved on 6 Nov and never landed. Confirm it is still wanted or retire it.

## 3. Redundancy and consolidation review
