- **ADR-005 (2026-10-30):** Advisory PR review. `.harness/scripts/pr-scope-check.mjs` checks a PR's scope (Target files while a slice is in progress, engine-file and dependency changes). `/review-pr` runs it and posts one CLEAN or NEEDS CHANGES comment. The person still merges. Claude never approves or merges, and the review is advisory so a Claude rate limit cannot block a merge.
- **ADR-006 (2026-10-30):** Reverted AI Studio commit c8cc4df's harness changes (kept ADR-004 and ADR-005 behavior: AI Studio rules, handoff injection, engine-folder guard, PR scope check, `/review-pr`, v2.2). Kept the React dashboard it added (`server.ts`, `src/`, `package.json`, `vite.config.ts`) as the operator's visual view of the harness. The dashboard reads commands, agents, settings, and spec files straight from disk, so most harness changes show up with no app edit. The one hardcoded list is `SPEC_FILE_PATHS` in `server.ts`; add any new spec or contract file there. Run it with `npm run dev`. It lives only in the hub and is not synced to spokes.
